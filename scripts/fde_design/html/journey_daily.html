User Journey B — The Returning Student’s Daily Loop
The habit loop that carries a learner from Stage 3 to Stage 18: every session follows the same five-minute-entry pattern.
Phase 1 — Return
1Sign in; the dashboard greets with streak, current stage, and last position
2One prominent button: Continue where you left off
↓
Phase 2 — Review (2 minutes)
3Check yesterday’s quiz result and any teacher feedback on a submission
4Skim the glossary terms attached to the current lesson
↓
Phase 3 — Learn (25 minutes)
5Open the recommended lesson; study one concept
6Complete its exercises; if it references a lab, the lab opens pre-configured
7Take the lesson quizDecision: passed? Yes → progress updates and the next lesson unlocks. Failed twice? The dashboard suggests the linked book chapter and books a lighter review quiz for tomorrow.
↓
Phase 4 — Confirm & close
8Stage progress bar increases; the roadmap marks the lesson done
9Tomorrow’s recommendation is queued; streak extends
10Session summary email optionally sent (weekly digest preferred)
Decision point — the flow branches as noted
