User Journey A — From Curious Visitor to First Completed Lesson
The critical first session: a visitor with zero computer-science background reaches a working understanding of FDE and finishes one lesson and one quiz.
Phase 1 — Discover (public pages, no account)
1Land on Home; read the plain-language introduction to Forward Deployed Engineering
2Scan Who this is for and the featured courses; open one course preview
3Open the Learning Roadmap preview and see Stage 1 is Mathematics
4Check the FAQ for “do I need experience?”Decision: convinced? Yes → create a free account. Not yet → browse the Book Library preview and return.
↓
Phase 2 — Start (account created)
5Register with email; no placement test — the academy assumes zero knowledge
6The roadmap automatically sets Stage 1 — Start Here, then Stage 2 Mathematics
7Pick a weekly goal (the default: 3 sessions of 30 minutes)
↓
Phase 3 — First learning loop
8Open the first short lesson (10 minutes, one idea, plain language)
9Try one interactive exercise with instant feedback
10Take the 3-question end-of-lesson quizDecision: passed? Yes → lesson marked complete. Not yet → the quiz explains each answer and offers one retry after a 2-minute review.
↓
Phase 4 — Habit forms
11Dashboard celebrates the first completion; streak = 1 day
12“Recommended next” is queued for tomorrow
13Optional: download the companion book chapter for offline reading
Decision point — the flow branches as noted
